Dual-core split
---------------

The PSOC™ Edge E84 has two Arm cores with fixed roles:

.. list-table::
   :header-rows: 1
   :widths: 15 85

   * - Core
     - Role
   * - **CM55**
     - Audio acquisition (PDM mic), noise suppression (AFE), wake-word detection,
       and command recognition using the DEEPCRAFT™ inference engine.
       Firmware lives in external QSPI flash (XIP mode).
       **DEEPCRAFT™ models generated by the cloud tool are compiled for CM55 only**
       and cannot run on CM33.
   * - **CM33**
     - Application host. Sends control commands to CM55 and receives detection results
       over the IPC pipe, then drives application logic — LED control, network,
       display, GPIO, etc.
       The application host can be any software that implements the IPC command set
       described below: bare-metal C, RTOS task, MicroPython script, or any other runtime.

All inter-core communication goes through the on-chip **IPC pipe**. The two cores
never share memory directly.

----

IPC communication protocol
---------------------------

CM33 → CM55 (control commands)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. list-table::
   :header-rows: 1
   :widths: 30 15 55

   * - Command
     - Value
     - Description
   * - ``IPC_CMD_START``
     - ``0x82``
     - Starts the Voice Assistant task on CM55.
   * - ``IPC_CMD_STOP``
     - ``0x83``
     - Stops (suspends) the Voice Assistant task.

CM55 → CM33 (status / results)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. list-table::
   :header-rows: 1
   :widths: 30 15 55

   * - Command
     - Value
     - Description
   * - ``IPC_CMD_VA_READY``
     - ``0xA0``
     - Voice Assistant initialised and ready.
   * - ``IPC_CMD_VA_WAKEWORD_DETECTED``
     - ``0xA2``
     - Wake word detected; listening for a command.
   * - ``IPC_CMD_VA_TIMEOUT``
     - ``0xA3``
     - Command listening timed out.
   * - ``IPC_CMD_VA_STOPPED``
     - ``0xA4``
     - Voice Assistant stopped (acknowledgement of ``IPC_CMD_STOP``).
   * - ``IPC_CMD_VA_ERROR``
     - ``0xE1``
     - Fatal error occurred.
   * - *intent index*
     - ``uint``
     - Index of the recognised command in the model's command list.

CM55 firmware code flow
-----------------------

.. mermaid::

   flowchart TD
       A[System Boot] --> B[Initialize BSP]
       B --> C[Setup IPC Communication]
       C --> D[Register IPC Callback]

       D --> E[Create VA Task]
       E --> F[Suspend VA Task]

       F --> G[Wait for IPC_CMD_START]

       G -->|START received| H[Resume VA Task]

       H --> I[Initialize PDM Microphone]
       I --> J[Initialize Voice Assistant]

       J --> K{Init Success?}
       K -->|No| Z[Send IPC_CMD_VA_ERROR]
       K -->|Yes| L[Set Command Timeout]

       L --> M[Send IPC_CMD_VA_READY]

       M --> N{VA Enabled?}
       N -->|No| N
       N -->|Yes| O[Capture Audio Frame]

       O --> P{Audio Enhancement?}
       P -->|Yes| Q[Process via AFE]
       P -->|No| R[Run VA Processing]
       Q --> R

       R --> S{VA Event}
       S -->|Wake Word| T[Send WAKEWORD Event]
       S -->|Command| U[Send Intent Index]
       S -->|Timeout| V[Send TIMEOUT Event]

       T --> N
       U --> N
       V --> N

       G -->|STOP received| W[Suspend VA Task]
       W --> X[Send STOPPED Event]
       X --> G

Application host requirements (CM33)
--------------------------------------

The CM55 firmware imposes no constraint on what runs on CM33. Any software that
can send and receive bytes over the on-chip IPC pipe can act as the application host.

A minimal host must:

1. Initialise the IPC pipe and register a receive callback.
2. Send ``IPC_CMD_START`` (``0x82``) to begin inference.
3. Handle incoming messages:

   - ``IPC_CMD_VA_READY`` — inference engine ready; user may now speak.
   - ``IPC_CMD_VA_WAKEWORD_DETECTED`` — wake word heard; listening for a command.
   - *intent index* — zero-based index of the recognised command; map to an action.
   - ``IPC_CMD_VA_TIMEOUT`` — no command heard in time; decide whether to restart.
   - ``IPC_CMD_VA_ERROR`` — fatal error on CM55; handle or reset.

4. Optionally send ``IPC_CMD_STOP`` (``0x83``) to suspend inference.

The `micropython-deepcraft-model-interface
<https://github.com/Infineon/micropython-deepcraft-model-interface>`_ library is one
ready-made implementation of this contract for MicroPython. Any other runtime
(bare-metal C, FreeRTOS task, Zephyr, etc.) can implement the same four steps directly.
