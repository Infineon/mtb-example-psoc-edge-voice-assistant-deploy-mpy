Welcome to DEEPCRAFT™ Voice Assistant Model Deployment on PSOC™ Edge documentation!

command machine learning model — created with the
`DEEPCRAFT™ Voice Assistant cloud tool <https://deepcraft.infineon.com/solutions/voice-assistant>`_

is structured for those who want to go further.
