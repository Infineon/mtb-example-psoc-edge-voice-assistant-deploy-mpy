System Overview
===============

The DEEPCRAFT™ Voice Assistant model runs on the **Cortex-M55 (CM55) core** of the PSOC™ Edge E84.
It handles audio acquisition from a PDM microphone, noise suppression, and continuous
inference to detect a wake word followed by spoken commands. Models generated by the
DEEPCRAFT™ cloud tool are compiled exclusively for Cortex-M55 (CM55).

The application layer — whatever acts on detection results — communicates with CM55
through a transport layer, sending control commands (start, stop) and receiving detection
events (wake word, intent index, timeout). In this enablement, that role is played by the
CM33 core running MicroPython over an on-chip IPC pipe, but neither a separate core nor
IPC are requirements: any host that can exchange the defined command set with CM55 should work,
whether over IPC, shared memory, a message queue, or a same-core call interface in a
future single-core configuration.

The first enablement of the application host in this repository is the CM33 core running
MicroPython, communicating with CM55 over the on-chip IPC pipe. The
`micropython-deepcraft-model-interface <https://github.com/Infineon/micropython-deepcraft-model-interface>`_
component provides the ready-made MicroPython bindings for this. Implementing a different host
— in C, an RTOS, or any other environment — requires exchanging the same command set
with CM55

To support a quick prototyping journey, this repository ships a deployment tool —
``deepcraft-voice-assistant-model-deploy.py`` — that automates the CM55 side end to end:
cloning the firmware repository, installing your model assets, compiling the firmware,
and flashing the binary to the board, all with a single command.

Read through to follow the steps and deploy your first
DEEPCRAFT™ Voice Assistant model onto the board.
